Tell me about a time you had to debug a particularly difficult issue. What was the problem, how did you approach isolating it, and what was the outcome?

    Situation: While setting up a machine learning project, I ran into environment errors when trying to install PyTorch.

    Task: I needed to get a working Python environment so I could actually run and test the model.

    Action: I isolated the problem by checking version compatibility between Python 3.13 and PyTorch's available wheels, found they weren't compatible yet, and used conda to create a separate environment pinned to Python 3.11.

    Result: The environment installed cleanly and I was able to continue development without further dependency conflicts.
